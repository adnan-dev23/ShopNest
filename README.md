# ShopNest — Modern D2C Lifestyle & Carry

ShopNest is a modern, high-performance D2C e-commerce platform engineered for lifestyle accessories, smart timepieces, and technical carry.

## 🚀 Live Demo
Visit the live store: [https://adnan-dev23.github.io/ShopNest/](https://adnan-dev23.github.io/ShopNest/)

## ✨ Key Features
- **Modern D2C Storefront:** Fast, accessible, and responsive catalog browsing.
- **Cart Drawer & Checkout:** Slide-over bag and client checkout system.
- **Visual Order Tracking:** Live order timeline with status updates.
- **Admin Control Panel:** Manage orders, sales value, and catalog data.

## 🛠️ Built With
- HTML5 / Modern CSS3
- Vanilla JavaScript (LocalStorage Reactive State)
- Deployed via GitHub Pages
